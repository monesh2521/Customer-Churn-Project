# Customer Churn Prediction — RabTech Academy Task 2

## Included files
- `problem_framing_memo.md` — project problem framing
- `responsible_data_card.md` — completed using the supplied template's headings
- `baseline_model.ipynb` — reproducible Python baseline notebook
- `risk_register.md` — risks and safeguards
- `customer-churn-training.csv` — supplied dataset

## How to run
1. Keep all files in the same folder.
2. Open `baseline_model.ipynb` in Google Colab or Jupyter.
3. If using Google Colab, upload `customer-churn-training.csv` to the notebook session, or upload the whole project folder to Google Drive and set the working directory.
4. Run cells from top to bottom.

## Important limitations
The dataset contains only 12 records. Metrics are for demonstrating the workflow only and are not reliable evidence of real-world performance. The data file does not document provenance, licensing, consent, or collection period; confirm these with the academy/data owner before public sharing. Do not publish row-level data if permission is uncertain.
